Verifier chống tự-mâu-thuẫn (label-neutral)

Chỉ flag mâu thuẫn nội-văn-bản / cấu trúc rồi bắt model quyết lại (tối đa 2 retry) — không bao giờ gợi ý nhãn:
  • Bất đẳng thức viết sai số học (-2.19 < -3)
  • Chữ verdict ngược với chính bất đẳng thức model vừa viết
  • Quote sai số so với observation của tool
  • Kết luận residual khi chưa gọi đủ 2 tool giai đoạn 2

Ensemble hoạt động thế nào

Mỗi case lấy đa số phiếu; hòa phiếu thì ưu tiên verifier-s11 (tất định, gates chắc nhất). Tổ hợp 3 phiếu = verifier-s11 + verifier-s4 + 1 run thinking tươi:
  • Hai phiếu verifier tất định làm mỏ neo (gates 48/48, bù trừ nhau: v-s11 mạnh C1/C8, v-s4 mạnh C4/C6) — phiếu thinking bơm C3.
  • Kết quả qua 5 lần gieo phiếu thinking: 83.3 / 80.2 / 81.25 / 79.2 / 79.2 → kỳ vọng 80.62% ± 1.7 (so với single thinking ±4.6).
  • Chi phí ≈ 2.6× base về compute; wall-clock ≈ một run thinking nếu chạy 3 phiếu song song.
  • 7 phiếu (5 thinking + 2 verifier) = 81.25% — thêm 4 run thinking chỉ mua thêm ~0.6 điểm.
